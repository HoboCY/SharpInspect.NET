# V1-25 棋盘格相机内参候选

关联工单：[Issue #26](https://github.com/HoboCY/SharpInspect.NET/issues/26)。

## 过程边界

`SharpInspect.NET.Calibration.OpenCvSharp` 是可选包，官方过程实现
`ICalibrationProcedure<CheckerboardIntrinsicsInput>`。输入包括棋盘内角点列／行数、
方格边长（毫米）、逻辑相机角色和完整 Effective Camera Configuration。
帧 ID、Session ID、Source Hash 由调用上下文提供；实际设备、绑定和成像修订仍由父会话绑定。
图像坐标是 ROI 内局部像素，整数位置为像素中心；普通对称棋盘没有带标记的绝对原点，
角点 ID 表示检测器的行优先顺序，不能用于宣称绝对板坐标方向已鉴定。

自动提取同时返回中立 `CalibrationExtractionReceipt`。官方过程以进程私有随机密钥签发
32 字节 HMAC-SHA256，绑定过程契约、规范输入、会话／帧身份、来源哈希、实际有效行像素
以及原顺序的每个角点哈希。计算验证这些精确绑定，使用已留存的首次提取结果，不再次检测。
重新提取必须产生新的观测；任何人工坐标变动、局部／整体重排或移用凭据均不能作为原自动观测计算。
公共离线调用者将 `extraction.Features` 和 `extraction.Receipt` 一起传入观测输入。

凭据密钥不写入数据库或证据文件。V1 开放会话在进程重启时中止，历史证据只读校验使用现有签名审计链；
凭据不能赋予重启后继续计算或发布的权限。托管宿主代码不是本包提供的安全隔离边界。

过程使用固定版本 OpenCvSharp4 4.11.0.20250506，原生运行时由测试／宿主选择。
OpenCV 的 [4.11 标定接口](https://docs.opencv.org/4.11.0/d9/d0c/group__calib3d.html)
定义针孔矩阵和 Brown–Conrady 畸变参数顺序。本过程保留 `fx, fy, cx, cy, k1, k2, p1, p2, k3`，
每张图的旋转向量（弧度）、平移（毫米）、覆盖、RMS 和逐点“检测减投影”像素残差。
过程不控制相机、PLC、存储、会话状态、政策或 Profile。

## 证据与兼容

系数只含矩阵和畸变相关值。独立 `CalibrationComputationEvidencePayload` 最大 64 KiB，
以版本化契约、规范字节与 SHA-256 绑定；输入与输出均防御性复制。
具体棋盘格证据由公共强类型 codec 解码，Runtime／WPF 不依赖 OpenCV 数学模型。
候选的父会话哈希绑定过程、原始观测和整帧排除理由；计算证据以 Frame ID、Source Hash、
Stable Feature ID 回连原始角点。数值汇总可在 WPF 直接审阅，详细结构保留在候选中。

不携带新计算证据或提取凭据的 T24 候选／观测与事件继续使用 V1 编码和哈希。
携带计算证据的候选、携带凭据的观测分别使用 V2 内容哈希，并通过 V2 事件保存；读路径严格分发并检查规范编码。
SQLite 仍为 Schema 14，Header／Frame Manifest 格式与存储绑定不变。
错误的系数契约不能成为候选；有界 `CalibrationProcedureException.ReasonCode`
作为失败会话原因留存，并走已有的基线恢复和终态审计路径。

## 冻结合成图片

数据在首次数值标定之前冻结，生成器完全使用 C# `Math` 射线平面求交，
不调用 OpenCV 投影、检测或标定。20 个姿态、640×480 Mono8、2×2 子像素采样，
棋盘为 9×6 内角点、25 mm 方格。

| fx / fy / cx / cy | 800 / 820 / 319.5 / 239.5 px |
| k1 / k2 / p1 / p2 / k3 | -0.12 / 0.035 / 0.001 / -0.0008 / 0 |
| Manifest SHA-256 | `1329D4C19AD2F781E47599710A5D200831A33CEB54E30CD97D837CC3EB13CC16` |
| Renderer SHA-256 | `B332ECAEA434B2795820B87227BEFCFAEE6648AECDAC8DAE3FFCAADE529E895F` |

测试先从真实渲染像素自动提取角点，再交给计算；独立投影仅作为预期比较。
预登记边界：角点最大 1 px；fx/fy 绝对误差 20 px，cx/cy 10 px，k1 0.08；
归一化半径 ≤0.25 内畸变函数误差 ≤2 px。
有限视场中 k2/k3 不必分别精确恢复，必须按冻结的畸变函数检查，不能事后修改数据或阈值。
这些是当前合成夹具的回归边界，不是统一生产样本数、0.3 px 门限或真实工位合格标准。
