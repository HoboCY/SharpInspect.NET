## 验收边界

Camera Recovery Cycle 由 Runtime 治理，默认重试间隔 5 秒、每周期最多 20 次，
部署可显式配置。整个周期保持 Ready=false；相机重新出现不代表生产准入。
每次只重开绑定的 Provider 和 Stable Device Identity，不能以发现顺序、IP 或型号选择替代相机。

重开后从头应用完整配置、读回 Effective Configuration、验证能力并准备原采集模式。
任一步失败不能保留本次部分配置或恢复此前中断的 Acquisition Attempt。
恢复与旧设备、真实异步调用及帧 lease 的归属一起验证；对外等待结束不等于物理资源已释放。

重试耗尽后停止自动尝试，并锁存 CameraRecoveryFailed。
授权人员显式开启新周期前必须完成身份、权限、适用 Step-Up 和持久审计；
新周期不自动 Ack、Reset 或 Arm。源健康恢复、报警复位、结果确认和生产武装是独立事实。
未确认结果、其他恢复流程及其他阻塞报警仍保留联锁。

SDK Callback Boundary 只允许有界校验、时间戳和计数采集，以及安全 lease 或有限复制。
回调栈不进入 Runtime 状态机、算法、UI、存储或用户事件；队列和帧池不能无限增长或临时分配绕过耗尽。
Provider 只报告类型化健康事实，Runtime 决定报警和恢复。
