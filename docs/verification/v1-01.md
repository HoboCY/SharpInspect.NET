## 实际执行范围

- OS：Windows 11 Pro x64，build 26200（SKU 48）。属于开发观察，未纳入 V1 正式 OS 声明。
- 编译 SDK：8.0.319。运行目标：net6.0 / net6.0-windows，已安装 Runtime 6.0.28。
- 初次依赖探测：测试 SDK 17.14.1 与 runner 3.1.1 不支持目标 net6.0；分别调整到
  17.11.1 / 2.8.2 后执行。未压制 TFM 支持错误。
- Runtime 9 项、WPF 13 项行为测试通过。WPF 消费宿主已实际跑通启动、拒绝、受理与完成、乱序、陈旧、换代、断流重连、导航和普通关窗。
- V101-U06 / U07 均先以失败测试复现，再修复：分别防止新 revision 排队后重新显示过期 Ready，以及一次全量请求失败后永远忽略同代次后续快照。
- 三个 NuGet 开发包已用独立消费目录和空包缓存恢复、构建并实际运行。最终综合运行 `artifacts/ticket01/20260907-181016-574/validation.json` 为 Pass（Runtime 9 + WPF 13，0 skipped）；脚本在运行前后比对同一 32 项源码文件集合及 SHA-256，未发现增删或内容变化。
- 同目录 `tests/*.trx`、`consumer-smoke.log`、`packages/*.nupkg`、`consumer-window.png` 分别关联测试、消费运行、交付包和实际窗口呈现。窗口已人工视觉检查；所有状态、原因和底部本机停止入口可见。
- 构建保留 `NETSDK1138`（.NET 6 已结束支持）提示；没有压制告警或提高包兼容下限。
- 重复运行保留独立目录；日志、TRX 和包内容由验证脚本关联到当前源码 SHA-256 清单。
