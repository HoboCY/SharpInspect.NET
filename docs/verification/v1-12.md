## 执行、所有权与唯一终态

公开 `AlgorithmExecutionService` 只调用已经成功准备的实例。入口接管 FrameBufferLease，所有拒绝路径主动关闭本次 owner；
重复使用同一令牌不会关闭另一个已经接管的 owner。一个引擎最多有一个实际工作占位，不排队。
PreparedAlgorithm 自身也有受锁保护的执行借用，因此跨引擎不能并发调用同一实例。
Dispose 在同锁内封闭未来借用，等待已取得的执行借用完成后才执行一次物理退休。

正常返回只携带不可变 AlgorithmResult；Runtime 独占 AlgorithmExecutionOutcome 构造权与 ExecutionStatus。
每帧绑定实例身份、算法身份、配置指纹、精确 Result Schema（含 Overlay Contract）以及同一个 Frame Metadata/typed correlation。
正常复用不调用 Factory/配置解析/模型准备/WarmUp。原有 sealed 值对象、只读属性与构造时防御复制保持结果不可变，
其封闭标量/图元结构不能携带 frame、Mat、SDK、UI 对象或任意对象图。

本票的引擎资源上限显式传入：MaximumExecutionTimeout 在 (0,5 分钟]，ShutdownWaitTimeout 在 (0,30 秒]。
这些是开发计算边界，不是隐式生产配方或资格参数。调用 timeout 必须正且不超过该上限。
单调期限从实例获得执行借用后的 attempt 构造时起算，包含任务调度、算法运行和完整结果校验。
整包校验后仍须在截止前且未被 Runtime 中止，才可在同一终态锁内固定 Success。
已经固定的终态不能由迟到返回、测量、Overlay 或异常改写。超时优先于之后的取消。

runtimeCancellationToken 是 Runtime 拥有的 abort 信号，不是 UI/远程调用方放弃等待的 token。
消费方 token callback 在独立有界 attempt 工作中执行；回调阻塞不能阻塞发出 Runtime 中止的调用方。
逻辑 Timeout/Cancelled 可先返回，但帧/实例/引擎占位保留至实际 Execute、校验和取消回调退出。
取消/超时请求退休实例；退休失败保留引擎阻断，不能自行创建替代对象。
正常 Success/Error 等待所有权清理完成后返回，使下一正常帧能立即复用。
测试内部 barrier 验证“执行借用后、启动前退休”和“算法返回后、校验跨截止”；公共构造/DI 不可安装这些回调。

## 整包校验与异常边界

按 Ordinal 精确核对 reason、测量键、标量类型和单位，不转换字符串数字，不填零，不丢额外字段。
校验 required、duplicate、未知值、null、有限浮点、整型/浮点范围、字符串长度和允许值。
返回 null 或任一违约统一为 Error + Unknown + AlgorithmResultContractViolation，ValidatedResult 为 null。
正常 Unknown 必须有绑定 schema 允许的稳定原因，可得到 Success + Unknown；产品 Fail 是正常结果，不自动创建设备报警。

Overlay 必须显式给出集合，空集合也检查确切合同 ID/version。校验闭集十图元、全部坐标、尺寸、半径、style/enum、
每项/总点数、元素数及文本上限。只允许封闭几何填充；不能让 renderer 静默丢弃无意义的 fill。
有限越界坐标保持原值，不做 clipping、clamp 或几何修复。字符长度与既有 OverlayText/OverlayContract 契约一致，
严格 UTF-8 有效性检查不把中文合法字符误判为同数目的字节超限。
文本采用保守纯标签子集：拒绝 markup、控制/格式/Bidi 字符、路径、常见命令/脚本词法及异常详情标记。
这不是对任意自然语言进行语义安全分类，也不构成 OS sandbox；正式消费方审查和诊断政策仍是后续准入条件。

AlgorithmExecutionException 的建议原因仅在当前 schema allowlist 内才成为公开 Error 原因；其他异常统一为 AlgorithmExecutionError。
无 Runtime 请求的 OperationCanceledException 不能自称 Cancelled。
Runtime 不读取、格式化、保存或扇出 raw exception message/stack/inner 数据。受保护异常详情本票不落盘。
每个 attempt 给算法独立 sink；缺少已准入诊断政策时一律 Dropped，只计数，不接受字段/对象。
终态后 sink 封闭，旧算法不能向下一执行注入事件或增加其活动期计数。内部 validator 至多返回 32 条问题，公开 Outcome 不带字段详情。
