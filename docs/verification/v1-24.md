# V1-24 独占标定会话与候选证据

关联工单：[Issue #25](https://github.com/HoboCY/SharpInspect.NET/issues/25)。

## 交付边界

Runtime 接受 `StartCalibrationSessionCommand` 后分配 Session ID，以独占标定模式协调采集、
自动提取、整帧排除、候选计算、原始证据查询与退出。`RunCalibration` 是单独的 Permission；
开始会话要求绑定完整意图的一次 Step-Up，后续操作重新检查同一个人、交互会话和授权修订。
已有默认角色与授权策略哈希保持不变；夹具必须明确授予新 Permission。

当前尚无真实 PLC 安全停线证明和 Released Recipe 准入权威，普通入口保持
`SafetyStopUnverified`。开发路径仅对精确匹配的 Virtual 设备、绑定、成像修订、基线设置、
标定方案与隔离存储启用。它保留 `Handshake.Unknown`、`Recovery.Required` 和 `Ready=false`，
不会伪造生产安全事实，也不创建 Inspection ID、生产算法执行或 PLC 结果交付。

## 过程与证据

过程使用编译期 DI 注册、精确版本描述符与类型化输入 codec。Runtime 在设备改变前验证输入，
调用前后核对不可变输入，限定并发、字节数和结果数量。过程只得到借用帧与类型化输入；
不提供相机、PLC、Runtime 状态、存储、DI 容器、发布或激活能力。

每次采集产生新的 Calibration Frame ID。图像转换为紧凑规范行，保存原始 stride 与完整来源，
使用像素哈希命名；临时文件刷盘并原子重命名，清单提交后才归还相机 lease。查询验证长度、
像素哈希与来源身份后返回独立副本。孤立与部分文件也计入容量，不能绕过上限。

自动观测保留稳定特征身份与原始坐标。整帧排除保留身份、时间与理由，并重新评估数量和覆盖；
计算开始后不再允许采集或改变选择，不能按残差删点或删样本。候选保留精确系数契约、
选择哈希、原始观测、质量指标与诊断，不产生政策验收、Profile 发布或激活权威。

实时快照的 `OperationInProgress` 覆盖命令执行与终态审计提交；阶段已显示 Collecting
不代表上一操作已完成。WPF 在操作结束后才启用下一次采集、排除或计算，仍允许请求退出。
用户会话失效会立即显示退出处理中；若失效发生于命令授权提交期间，恢复工作等待该命令任务
发布并结束，避免两个恢复过程争写终态。该极短授权交错由独立代码审查核对，未宣称具备
精确暂停在耐久授权和任务发布之间的确定性测试设施。

## 相机恢复与关停

Camera Recovery 是唯一物理设备 owner。标定临时申请与实际读回值在首帧前留存，
基线完整 Requested／Effective 来自准入时的实际设备。退出、取消或失败执行恢复及读回；
物理恢复完成后，还须提交会话结局和 Start 命令终态，才确认释放独占 fence。
日志写入失败也执行物理恢复，缺少耐久证据时继续禁用。

不合作的过程超时后，相机可先恢复；借用的托管图像副本与独占 fence 一直保留到实际调用返回。
内部取消信号独立于过程注册的同步回调。关闭先等待完整物理恢复预算，再等待实际过程和终态提交。
若仍不结束，`DisposeAsync` 明确抛出 `CalibrationShutdownIncomplete`，投影保持禁用与独占，
不报告正常 Stopped、不提前归还借用副本；host 必须处理异常终止，重启后继续恢复。

## 存储边界

Schema 14 是显式扩展，要求签名审计、Local Identity、Camera Setup、Camera Recovery 和 Imaging Setup；
Camera Network、算法结果归档与 Recipe Draft 仍可选。Schema 1–13 不自动升级。
会话准入与身份授权在同一事务提交，后续事件按已接受意图留存。
会话头、事件与原始帧清单分别绑定签名审计条目及专用位置，验证载荷和位置的一一对应；
重算普通哈希不能替换已签名内容，缺失事件或孤立清单会使完整性校验失败。
已恢复会话若仍有已授权而未写终态的操作，重启只补记该操作失败，不重新打开相机。
待完成操作必须匹配原会话的 actor、交互会话、授权修订与 Runtime epoch，且不携带新的
Step-Up grant；即使该操作有合法签名，身份关联不符也拒绝读取并阻止启动恢复继续。
默认上限为 100 个会话、10,000 个事件、单事件 256 KiB、每会话 64 帧、单帧 16 MiB、
图像总量 256 MiB；配置可以收紧，硬上限独立校验。
