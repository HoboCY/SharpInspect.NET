## 实现边界

导入包是数据，不能装载代码或指定解包路径。内容寻址文件由独立 SQLite 导入记录引用；
文件存在本身不产生权限。读取和冷启动完整性校验包含实际包文件，缺失或篡改会拒绝读取。
schema20 为导入记录使用独立审计位置与新审计封装，旧 GVC1 治理记录和旧格式的字节保持原义。
导入与历史选择须显式配置 `CalibrationImportStoreOptions`；旧数据库不会因使用新命令而自动迁移。

本地重验显式解析已注册的精确 Calibration Procedure，重新提取保留的图像并重算系数与政策指标。
它不创建虚构的本地 Calibration Session，也不继承来源安装的发布或生产权。
本地物理验证由项目明确注册的验证器处理独立证据；运行时提供当前设备租约与成像条件的本地执行记录。
这不替代实际量具、设备、算法或生产资格验收。

本票发布的导入 Profile 仍为 DevelopmentOnly，ProductionAuthority 与 CanActivate 均为 false。
历史选择也必须满足当前政策、物理有效期和精确兼容性；所有尚未交付的生产资格检查继续拒绝。
候选失败与激活失败不改写历史系数、不自动选择备用 Profile、不自动 Ready。
