## 实现边界

`ICameraProvider` 保持只读发现与按稳定身份打开。支持网络维护的 Provider 可实现
独立的 `ICameraNetworkConfigurator`，通过独占维护会话读取、检查和修改 IPv4 部署配置。
普通 Virtual Provider 不提供该扩展；网络 Virtual Provider 是显式选择的开发夹具。

命令指定完整 Provider/Stable Device Identity，不要求先成功打开或绑定相机。
Step-Up 使用 `ManageCameraBindings` 权限、操作 ID、命令种类以及目标身份哈希。
工位网络来自宿主注册选项，不能由命令覆盖。V1 接受规范的十进制 IPv4 单播主机地址，
前缀长度 1–30；相机地址必须匹配工位声明的子网，并通过 Provider 可检测的冲突检查。

Runtime 在 Ready=false、Disarmed、无检测或待交付结果时建立维护占用。
已注册的采集或恢复服务仍拥有设备时拒绝维护。目标 debug device 必须实际关闭后才允许取得维护会话。
维护期间 Provider 阻止同一设备被 Open，Runtime 阻止 Arm 及其他 setup mutation，Stop 不等待整个物理操作。

实际旧值、请求新值、目标身份、操作者、工位网络、准入和终态进入受保护的持久审计。
修改后必须重新发现同一稳定身份并读回请求值。成功保持 Ready=false，并要求之后独立执行完整 Recipe Activation。
Binding 不随网络地址自动变更，激活和恢复不自动修复 IP。

调用方超时不等于 SDK 调用结束。真实调用及维护会话清理完成前继续保留设备、工位维护占用和 setup 串行锁。
修改结果无法证明或审计终态无法持久化时保持 Unknown；重启发现未终结或 Unknown 记录时要求显式协调处理，
阻止 Network/Rebind/Apply/Arm，不自动重放或推断修改失败。

当前开发工位尚未注册 PLC 或结果交付所有者；启动快照的 Handshake=Unknown、Recovery=Required
并不代表存在待确认结果。维护验证同时要求 PendingDeliveries=0、无当前检测及无交付等待状态，
不会将启动 Unknown 改成 Idle。以后接入 PLC/结果交付所有者时，仍须由其提供可信的无交付占用证明；
本票夹具不能代替该生产验收。

SDK 取消回调也属于未结束的物理工作。取消请求通过异步任务派发，对外超时与 Shutdown 不在调用方
执行 SDK 回调；会话实际 Dispose 必须等待这些回调结束。调用方超时返回独立的 Unknown 结果，
不覆盖后台所有者已经写入并发布的终态，也不将仅有准入审计的超时结果声称为终态已持久化。

维护查询从授权前开始计入容量，每个 coordinator 最多保留 16 个查询，其中最多 4 个进入实际授权和
数据库读取。排队和对外等待使用操作时限；后台读取忽略取消时仍保留实际占用直到结束，不能通过反复超时
创建更多读取任务或连接。查询本身不会发布工位状态变化。

## 持久化边界

schema12 通过 `CameraNetworkStoreOptions` 显式开启，要求相机设置、身份与审计存储；相机恢复、
算法结果归档与配方草稿保持可选。旧库不隐式迁移，所有已配置组件共用 SQLite 连接时使用其中最大的
单值上限，各账本仍按自己的签名配置限制记录大小和总量。

网络准入在同一事务内预留未来终态需要的三个审计条目、一个网络记录和一个最大 payload。
普通写入、其他准入和拒绝记录不能消费这些预留。终态使用原准入的身份和授权证据，不因之后退出会话
或权限变更而拒绝记载已经发生的物理操作。未认证请求的 GUID 仅保留在 claimed 字段，不能成为真实操作者。
账本读取在逐行分配和解码前检查行数、编码长度与累计字节预算。

独立只读审查已完成，无未关闭 P1/P2；覆盖协调器、设备租约、Virtual 地址竞争、
schema12 准入/终态事务、资源上限及授权归因。审查者未另行运行测试，实际结果以上述门禁为准。
生产设备所有者拒绝的 Runtime 测试使用拒绝回调；真实 DI 下分别注册采集/恢复服务的网络维护拒绝
尚未独立执行，该接线目前只有静态审查证据。

真实相机与厂商 SDK、实际网络冲突检测能力、Host Network Mutation、Provider Qualification、
Station Acceptance、Native Crash Isolation、正式发行及生产准入均为 **NotRun**。
Virtual 开发夹具不修改 Windows 网卡或任何实际设备地址，其通过结果仅证明本票已执行的开发验证范围。
