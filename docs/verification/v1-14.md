## 结果与历史契约

`AlgorithmResultArchive` 只接受引擎内部构造的成功 `AlgorithmExecutionOutcome`，
在写边界重新验证完整结果。Production、非 Success、缺少已验证结果或超出容量均整体拒绝。
存储类别固定为 `DevelopmentComputation`；它不是 Core Inspection Record、正式 Manual/Qualification
执行记录或发布许可。存储成功只表示开发计算历史已提交，不开放 ResultValid、Outbox 或生产准入。
每个归档服务在编码前最多接纳 4 个未完成请求，超出时即时拒绝；槽保留至写入结束，
编码与写入共用同一提交 deadline，避免先生成大量文档再排队等待存储容量。

规范 JSON 包含 RecordId、类型化执行关联、FrameMetadata、算法及配置 schema 身份和 hash、
完整结果 schema/constraints/reason codes、完整 Overlay Contract、结果、painter 顺序、
Recipe/执行政策/单调时间证据及 renderer contract。配置值与模型路径不进入此文档。
位置和 UTC 记录时间由 SQLite 单写事务分配并进入签名绑定；相同 RecordId 与相同 payload hash 幂等，
同 ID 的不同内容或同执行关联的另一记录均冲突。有效空集合有完整记录，不合成缺失结果。

UTF-8 编码、解码、字段集合、discriminator、枚举、数组、深度、hash 与重建契约均受校验。
解码使用记录内的原 schema，不查当前算法包；未知格式或 renderer contract 不尝试升级或修复。
历史结果整体重验失败时不返回部分测量或图元。

## SQLite 与只读查询

`ProductionStoreOptions.AlgorithmResultArchive` 是显式开关，必须同时提供本地身份与审计政策。
启用时只从新空库创建 schema 8；旧库返回受治理迁移要求，不自动升级。
未配置此能力时原 schema 1/2/7 路径保持原版本；打开已有 schema 8 必须提供一致配置。

结果与其签名审计条目经现有单写队列在同一 SQLite 事务追加。版本化审计封套增加结果位置绑定，
验证读取原文、重新计算内容 hash 并比对全部索引身份；页面外的结果也不能绕过完整验证。
只读查询使用独立连接与一致读事务，按 position 和固定 ThroughPosition 分页。
完整核验超出政策预算则返回不可用，不把尚未覆盖的历史显示为已验证。

开发默认上限为单记录 1 MiB、单页 4 MiB、总归档 256 MiB、10000 条；较低显式上限同样受绑定。
这些上限共同生效，不保证先达到条数上限。schema 8 还受共享审计链完整核验条数预算约束；
归档保留 64 条非归档控制事件空间，该固定规则进入配置签名绑定。
命令、身份、报警和归档的审计追加均在事务内检查下一序号，超过共享硬上限时整体回滚并返回容量拒绝。
容量耗尽不会追加一条已知无法完整核验的事实，也不被解释为历史结构篡改。
SQLite 单值限制、写入检查、审计绑定及读路径同步识别 schema 8。
旧版本只读访问、取消、队列容量和后置完整性检查保留既有 fail-closed 约束。

## 纯显示与图像身份

WPF 只接收 Runtime 验证后的封闭 `FrameOverlaySnapshot`。图元闭集为 Marker、Line Segment、
Arrow、Polyline、Polygon、Axis-Aligned Rectangle、Rotated Rectangle、Circle、Ellipse 和 Text。
输入帧左上像素中心为 `(0,0)`，X 向右、Y 向下、顺时针角度，裁剪边界为半像素帧边界。
按集合顺序绘制，描边、填充、虚线、尺寸与文字解释使用版本化 renderer contract。

`OverlayText.AnchorKind` 决定 Text 几何锚点，`OverlayMarker.Size` 决定 Marker 几何尺寸。
Style 中同名用途的字段保留原值，但不参与这两个几何决策，兼容此前允许字段不一致的合法结果。
缩放、平移、DPI 和裁剪只生成显示数据，不回写持久几何；无法安全呈现时整幅不可用，不能漏画后声称完整。
全部出界、有效空集合、未选择及无法读取结果分别解释。

`FramePreviewImage.CopyFromFrame` 从有效原帧复制冻结的未标注显示图，同时绑定原始像素摘要和完整帧元数据。
它是开发预览身份，不是正式图像 EvidenceHash。原图未保留时仍能显示结构化 Overlay。
渲染产生不同的 `RenderedOverlayPreview` 类型及独立身份，绑定源预览、结果 hash、renderer、视口与 DPI；
派生类型不能被当成原图传入查看器。Mono16 显示归一化不改变原帧像素。

查看器消费只读 `IAlgorithmResultQuery`，筛选变化、关闭和迟到响应不能恢复旧页面或旧几何。
窗口不拥有数据库连接、SQL、归档写入口或几何回写动作。文字是 literal text，无 XAML/HTML/URI 加载路径。
