## 交付边界

交换采用固定成员的无压缩数据容器。规范清单和成员哈希由 ECDSA P-256/SHA-256/P1363 签名覆盖，成员路径不用于文件提取。输入只进入有界内存暂存；未知成员、链接／压缩标志、路径攻击、重复项、截断、超额和尾随内容均拒绝。验签公钥只能来自接收工位当前批准的独立 Recipe Trust Store。

导出选择精确本地 Draft 或 Released Snapshot。可移植投影排除本地 Schema 字段元数据、帮助、默认值、显示名称、迁移权威和设备绑定；不透明 Provider 扩展与旧式具体 Calibration asset 拒绝交换。算法字段必须同时具有绑定到 Schema 哈希的 `PortableRecipeData` 分类和本地版本化政策许可。默认 `LocalOnly` 和显式 `Sensitive` 不能由白名单覆盖。接收端只使用已注册的精确本地 Schema，校验不调用算法工厂、语义回调、迁移器或 Provider。

字段分类使用新增构造入口；原构造签名及全 LocalOnly 的 Schema 哈希保持原契约。需要分类的 Draft 使用格式 6；历史格式 1–5 的编码与哈希不变。

Import/Export 检查专门的 authenticated Human Permission。信任替换及签名键创建／退休强制精确一次性 Step-Up；信任版本和密钥状态独立于审计签名域。私钥由 Windows LocalMachine DPAPI 保护，并绑定 Station、KeyId 和公钥指纹，公共历史不返回私钥密文。KeyId 创建后不可复用。

同一 SQLite 事务重新检查身份、信任和签名，创建新 DraftId、新 RecipeKey 及不可变来源。来源包含可空 SourceStationId 和完整 descriptor hash，并参与审计绑定及重建校验；任一字段篡改均使交换与普通 Draft 查询拒绝。外部生命周期只保留为来源，不能授予本地发布、批准、Active 或资格。后续本地编辑保留来源，普通本地发布重新运行算法验证并记录本地批准。

Import 精确重放返回原持久 Outcome 与 AttemptId；无法恢复原产物的其他交换命令重放明确拒绝。取消、容量拒绝、身份撤销及篡改不能留下半导入。schema24 的既有读写入口验证交换账本，同时保留可选旧账本及会话终态预留。资格会话额外预留尚未接受的首个 Exit 行，覆盖身份、命令与账本写入；接受 Exit 后释放该份预留，恢复尾继续保留，Closed 后归零。
