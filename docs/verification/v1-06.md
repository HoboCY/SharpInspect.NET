## 交付范围

`Permission` 是逐动作授权契约，`HumanRoleBundle` 只负责默认赋值。个人主体、权限集合及授权修订保存于
签名保护的本地身份状态；显示 claims、Windows 管理员、调用方传入的 ID 和角色标签都不能授权命令。
创建带角色账号要求 `ManageAccounts + ManagePermissions`，防止仅持有账号生命周期权限的人创建更高权限账号。
禁用、解锁、重绑和权限调整分别使用其专用权限；管理必须保留最后一个可用管理员。
凭据因失败限额全部禁用后仍需后续 Recovery Kit 流程，本票没有重启或编辑 SQLite 的恢复旁路。

`IStepUpAuthentication` 消费配置的 `IIdentityProvider` 真实身份结果。Grant 绑定人员、会话、具体命令类型、
权限、命令 correlation、目标、凭据 ID、授权修订和政策 hash；新鲜度使用单调时间。最多 32 个未过期 Grant，
成功提交后消费一次；锁定、换人及相应权限变更使旧 Grant 失效。密码、验证器和机密身份状态不会写入安全事件。

`IStationRuntime` 在 SQLite writer 的 `BEGIN IMMEDIATE` 之后读取当前签名身份状态，并在短期 Session lease 下
检查当前主体、Enabled、Permission、Grant、取消和已受理 correlation。账号状态、授权变更前后集合、实际人员、
Step-Up 消费及 Outcome/Completed 共用一次事务；提交失败全部回滚。输入校验、密码派生及审计可用性等待位于
Runtime 命令锁之外，拥有 2 个实际准备槽与 16 个总请求限制；只读授权查询限制为 4 个并发、16 个总请求。
预检从不替代事务内鉴权。内部准备超时返回受控拒绝，不把内部取消异常暴露给未取消的调用者。

非交互服务使用独立 `SystemPermission` 和固定 System Principal 目录。当前实际命令记录者仍为
`SharpInspect.Runtime`；管理命令另记录已验证的 Human ID。本机 Stop 不借用人员身份，仍要求本机来源及持久审计。
当前开发 Runtime 缺少生产、设备和资格能力，始终不能进入 Ready。

Schema5 仅从新空库创建。身份载荷规范编码为 42 字段，包含认证和授权政策、实际人员/会话、动作/目标绑定及
权限变化摘要；状态封印绑定最后一条身份事件，后续命令终态不会错置该位置。带本地身份的 schema4 只读预检拒绝
`IdentityAuthorizationGovernedMigrationRequired`；schema3 保持 `IdentityAuthenticationGovernedMigrationRequired`。
本票没有历史迁移器。账号数量最多 16，同时受 32 KiB 机密状态上限约束。

## NotRun 与后续能力

Windows 10 正式发行矩阵、真实物理 Windows 锁屏/RDP/快速用户切换、发行硬件的密码计算耗时资格、设备/PLC、
断电耐久性、正式身份 Provider Qualification、Station Production Acceptance 与生产 Ready 均为 NotRun。
本机 Windows 11、SQLite、DPAPI 和受控 Provider/排程测试不构成安全认证或现场合格。

生产政策、Recipe/Deployment 信任根、配方签名键、设备绑定、恢复及发布命令的实际状态机随各自 ticket 交付。
本票固定其专用 Permission 和强制 Step-Up 规则；现有审计治理命令贯通授权后仍以
`GovernedCapabilityUnavailable` 拒绝实际变更，没有通用 Execute 或任意服务定位入口。
持久审计不可用、资源耗尽或调用 deadline 到期时只返回 `Audit=Unavailable`，不伪造已记录的拒绝或成功。
进程中未消费 Grant 不跨重启恢复；审计失败重试只适用于未提交的本次请求，不修改历史事实。
