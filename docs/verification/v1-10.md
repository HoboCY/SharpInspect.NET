## 契约与实现边界

消费宿主显式向 DI 注册 Factory，Runtime 不扫描程序集、加载插件目录或向执行上下文传递容器。
Abstractions 与 Runtime 保持托管、无 UI，不依赖 WPF、OpenCvSharp 或厂商类型。
Factory 的不可变 Descriptor 绑定算法身份、配置 Schema、结果 Schema 和 Overlay Contract；
准备请求还显式提交结果与 Overlay 的身份、版本和 hash，缺项、旧版本及内容替换均在 Factory 调用前拒绝。

配置类型封闭为 Boolean、Int64、Float64、String、Enum。Snapshot 防御性复制全部输入，
拒绝未知/重复字段、缺必填值、类型/单位不匹配、约束违反、非有限浮点和非法 UTF-8。
authoring default 不能补齐生产请求；可选项缺省保持缺省，不隐式迁移、转换或截断。
`sharpinspect-config-v1` 按 Ordinal 键排序，使用严格 UTF-8、长度前缀、类型标签和大端整数，
Int64 不经过 double；Float64 保留 IEEE-754 位值并将正负零归一为正零。
SHA-256 绑定 canonicalization 版本、Schema 身份/版本/内容 hash、单位和全部值。
Schema hash 还绑定约束和 authoring defaults；枚举允许集合按 Ordinal 排序。
结果 Schema hash 绑定测量约束、原因码及完整 Overlay Contract，结果字段禁止 authoring defaults。

准备按结构验证、算法语义验证、创建及预热的次序执行。Factory 对模型、许可证、设备计算资源或模板的
具体准备由消费方负责，本票不虚构生产依赖。任何失败都不交付句柄，错误使用封闭原因码，
不把消费方异常消息、路径或凭据反射到诊断。成功句柄不公开原始算法对象。
最小执行上下文仅提供类型化相关身份、不可变配置、只读借用帧和有界结构诊断；没有设备、PLC、数据库或 UI 能力。

准备总期限显式指定且不能超过部署选项的最大值，计入结构验证和排队；与 Recipe 执行期限分别配置。
运行代码通过后台工作开始，同一 Factory 串行，实例使用引用身份确定唯一所有者。
取消通知和 Runtime 等待各用独立令牌，消费方阻塞取消回调不能阻塞调用方取消返回。
实际创建、预热、取消回调以及未交付实例的释放全部结束后才释放准备槽。
超时不会使后来的准备替换仍在运行的工作，也不会交付迟到实例。
弱引用历史标记防止 Factory 重用已释放对象；第二次返回已有对象不释放原所有者的资源。
失败释放保留所有权占位；关闭等待到期不宣称完成释放，也不产生 Ready。

默认开发资源界限为 4 个并行准备、16 个所持实例和 2 秒关闭等待；允许显式配置，
分别限制在 1–16 个准备、最多 256 个实例、最多 30 秒关闭等待、最多 5 分钟准备期限。
最多显式注册 64 套 Factory，配置/测量字段各最多 256 个，单个标量文本最多 4096 UTF-8 字节。
这些是本票开发实现的资源界限，不是已完成性能资格的产线政策。

## 验证记录

R09 初次定向运行失败：返回 AlgorithmPreparationTimedOut，预期 AlgorithmPreparationCancelled。
实际原因是 Runtime 等待也使用暴露给算法的令牌，算法阻塞回调挡住等待注册的取消通知。
改为独立 Runtime 等待令牌后，R01–R12 定向测试 12/12 通过；原始失败不能解释成已通过。
配置审阅另发现 Enum 错误 accessor，以及修订时 String/Enum 共享约束分支的类型回归，
均以对应枚举和混合类型回归验证，未以旧测试通过代替新边界检查。

完整门禁：`artifacts/ticket10/20260908-032805-633/validation.json`，结果 Pass。
360 项测试通过（Runtime 296、WPF 64），零失败、零跳过；163 个源码、测试、样例及工具文件的
路径集合和 SHA-256 在门禁前后相同，完成后再次核对当前文件为零 hash 失配。
Release 构建、三个开发 NuGet 包、隔离包缓存消费者、实际 WPF、独立重开、审计/身份/报警负向场景
及双 Factory 准备消费全部通过。C01–C11、A01–A09、R01–R12 均包含在本次 Runtime 测试中。
外部程序集继承 OverlayPrimitive 的定向编译探针得到预期 CS1729，证实构造器没有外部继承入口。

构建仍保留 net6.0-windows 结束支持的 NETSDK1138 提示，开发包仍提示未嵌入 README。
