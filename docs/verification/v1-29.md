## 实现边界

消费方在 WPF 层显式提供编辑器 Factory 实例及精确算法身份、Schema ID / 版本 / 哈希。
注册表冻结描述并限制数量，不扫描目录、安装代码或通过通用容器创建扩展。
编辑器身份是注册诊断契约，不充当程序集来源证明，也不进入生产配置或替代真实作者。

扩展只获得 `IAlgorithmConfigurationDraftEditContext`：读取不可变的 Schema / 配置工作副本、
以编辑修订号提交完整配置替换、请求同一路径的完整草稿验证、报告自身失败。
它不获得 `RecipeDraftEditorViewModel`、`IRecipeDraftEditor`、身份会话、Runtime、算法实例、
设备、PLC、数据库或 `IServiceProvider`。保存和再次认证使用宿主现有命令。
自定义视图不继承宿主 ViewModel 的 DataContext。

完整替换先经过相同 `AlgorithmConfigurationSnapshot.Create` 的类型、单位、必填、范围及
规范化校验，再一次更新通用编辑器持有的字段工作副本。未改变值保留作者默认来源；
实际修改值成为显式输入。相机、政策、资产、标定要求和迁移谱系均继续由原完整草稿
构造及保存路径保留。合法结构的算法语义错误由既有完整草稿验证和 Runtime 保存拒绝。

结构非法候选不会改变最后接受的值或内容哈希，但当前自定义会话被标记为存在未接受
输入，保存保持禁用；直接调用保存方法也不能绕过此状态。下一次合法替换解除状态。
用户明确回退或扩展故障时，撤销上下文并卸载自定义视图，丢弃未接受输入，通用编辑器
继续显示最后接受的配置。重新打开草稿不会自动创建或调用自定义编辑器。

上下文绑定当前草稿工作副本代次和真实会话；新建、重开、清空、锁定、页面卸载或切换
编辑器时撤销旧句柄。编辑修订号防止旧候选覆盖通用编辑器的新输入；初始化期间只读，
挂载成功后才允许编辑。验证或保存繁忙期间拒绝重入修改。

本能力属于消费方显式注册的受信进程内 WPF 扩展。受控 Create / View / Refresh / Dispose
异常和主动失败报告触发通用回退；不承诺隔离恶意程序集、强制终止堵塞 UI 的代码或
捕获扩展自己安排的任意异步回调异常。消费扩展需及时返回并报告自身受控故障。
