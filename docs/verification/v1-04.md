## 事务、格式与信任边界

本地身份仅在全新 schema3 空库启用。schema1/2 转换在只读 preflight 拒绝，未实现隐式迁移。
IdentityConfigured/Bootstrap/Authentication/RecoveryKitIssued 等闭集安全元数据与命令事实共用
全局审计链、检查点、单写队列和 COMMIT 边界。Schema3 的类型及可空来源序号均包含在规范 envelope hash，
SQL CHECK 同时限定事件类型、正序号与互斥关系；schema2 的既有字节格式不变。
每次写入重新验证可信检查点至尾部，历史仍按有界段轮转。Verified 仅证明报告实际覆盖的范围。

唯一机密状态包含单向验证器、消费/撤销状态及版本，受机器 DPAPI 保护，并由数据库外受限密钥签名。
签名绑定 Station、安装密钥 ID、状态 revision、最后身份审计 sequence 和密文；密文同时固定完整身份政策 hash
及最后身份事件的链 hash，防止同 revision/sequence 的不同历史分支拼接。不把机密证明材料放进审计。
只修改 DPAPI 密文不能替换密码；回放旧状态行也必须匹配最新身份审计位置。
机器、数据库和私钥同时失陷，以及整套本机历史回滚，仍服从 V1-03 的信任边界。

公共 IPasswordHasher 契约支持将来演进；V1 本地权威库明确只接受 sealed PBKDF2 实现，避免调用方
宣称虚假工作因子。政策钉住算法/格式/参数版本/发行最低值；目标工作因子和基线标识可以提高，
旧验证器只在成功登录后通过凭据 ID + revision 比较并与成功证据原子升级，不降低旧工作因子、盐或输出长度。
实际基线、目标及记录工作因子作为非秘密元数据入链。

BootstrapToken 为 256 位随机量，默认 15 分钟。成功或观察到过期后不可重用；持久时间水位防止
已观察到的到期因系统时间回拨而复活。Recovery Kit 的明文只存在一次交付结果和当前进程的待领取对象中。
已提交 bootstrap 返回成功后，取消不能把它改报失败或自动销毁未领取的包；切页遮蔽已显示内容。
显式清除或进程释放会销毁待领取对象；进程终止后不能从权威库恢复明文。
