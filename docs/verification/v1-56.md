## 事件与算法边界

`LoggingDiagnosticsPolicy` 显式冻结事件代码／版本、组件、级别、字段分类、数值范围和有限符号集合，
以及每次执行的事件／字节、全局窗口速率、属性／符号大小、活动作用域、各输出队列的普通／高等级预留容量、
写入超时、滚动／保留、健康窗口、flush、查询和后续临时 capture 的上限。基线不能永久启用 Trace／Debug。
`ProductionStoreOptions.LoggingDiagnostics` 绑定此策略及两个实际安装目录；没有隐藏的生产数值。

请求尚未分类，不能直接序列化。Runtime 的分类器只接受闭合标量类型，在构造不可变投影后才调用显式 JSON 写入器。
未知事件／版本／字段、重复字段、禁止字段、任意对象、未批准字符串、超范围数值和非有限数值均被拒绝。
不读取对象 getter，不调用任意对象 `ToString`，不展开异常／字典／对象图。
密码、Token、恢复码、私钥、verifier、原始工件码、图片、配方、数据库页和内存转储不能进入任一输出。
即使使用批准的字段名，任意秘密文本也不能混入有限符号集合。

算法 ABI 保持 `AlgorithmDiagnosticEvent`／`IAlgorithmDiagnosticSink`；当前适配器使用事件版本 1。
算法只取得独立的本次执行 scope，不能通过 sink 引用 Attempt、帧、配置、准备实例或下游 provider。
Runtime 固定 Epoch、事件身份、UTC 时间及实际 Execution Correlation；终止与发射使用同一有界内部临界区。
成功、错误、取消和超时均封闭 scope；迟到请求拒绝。执行器在本次执行开始时取得当前已激活管道，
不会因启动时管道尚未完成激活而永久失去诊断。

标准事件包含算法计算的终态摘要、诊断丢弃摘要和边界异常。算法终态日志不代表 Core 提交或 PLC 发布成功。
异常只尝试在拥有边界发射一次：Safe 仅含固定 Owner／Category 与由这些批准符号生成的稳定指纹；
HResult 仅进入 Protected。不读取异常 Message、StackTrace、Data 或内部异常图，不散列秘密原文。
一次性边界是 best-effort、至多一次发射，并非恰好一次持久化；部分扇出／额度拒绝后不重试制造重复。
中央审计、Core、报警历史和交付义务继续使用各自的权威事务契约，不能由日志补写或替代。

有限符号与语义范围是消费方审核过的契约；这不是识别所有秘密或阻止恶意算法利用批准数值进行隐蔽编码的沙箱。
算法及第三方程序集仍受 ADR-0090 的受信集成和副作用边界约束。

## 输出、实际物理所有权与查询

Safe、Protected 和可选 Safe 转发器各有独立队列、字节／记录上限与一个固定线程。
生产调用不等待下游 IO；队列争用或饱和时立即丢弃，Warning 及以上保留独立容量。
正在执行的记录仍计入额度。抛异常或超过写入时限后禁用该路；不会替换线程、重试或提前释放未完成的物理调用。
flush／关闭等待有上限，未退休的调用、载荷和文件所有权保留至实际完成。
聚合计数和各 sink 的队列／物理调用／失败状态可查询，健康告警只提交固定代码 `DiagnosticPipelineUnhealthy`
和来源 `Runtime.Diagnostics`，生产影响仍由显式 Alarm Policy 决定。

两路为独立固定 NTFS 目录，Safe 使用滚动 UTF-8 JSON Lines，Protected 使用独立额度和更短的保留。
安装只接受已存在直接父目录中的指定空目录／新目录；拒绝云同步路径、重解析祖先、非本地固定 NTFS 根。
目录和文件的受保护 ACL 只允许运行身份与 BuiltinAdministrators，owner 也必须属于批准集合。
安装绑定包含策略／目录设置、卷和文件身份、运行 SID、owner 与 DACL；仅规范化 Windows 的非权限性
`AUTO_INHERITED` 状态位，实际 ACE、protected 位或根身份变化仍拒绝。没有管理员／离线读取保护声明。

激活 worker 必须实际取得两路独占写者，并执行目录／ACL／盘点验证，才发布可用管道。
两路均不得与数据库目录、已配置的标定证据、图像暂存／最终目录或隔离区重叠。
每根目录保留一个已知的零字节 `.diagnostic-writer` 控制文件；无跟随句柄禁止另一个实例／进程取得写权，
祖先目录保护与该句柄持有到实际退休。该控制文件不属于 JSONL 记录、滚动或删除对象。
日志文件及删除对象均检查单链接、非 reparse、身份、路径与 ACL；过期删除使用同一已验证句柄。
文件名封闭 `创建时间 + rollAfter + retention` 的到期值，超过 append window 不再追加，重启不续写旧文件；
文件系统 mtime 不决定到期。容量不足只能拒绝，不能提前删除未到期内容。
与数据库同卷，写前保留量取固定字节与卷百分比上取整的较大值，未知卷空间拒绝。

历史读取只有一个物理查询槽，调用方超时不会释放仍运行的 IO。记录、返回字节、文件和总体扫描字节有界；
结果为能容纳的最新完整后缀，不用更旧文件填补较新记录被额度省略后的空隙。
磁盘内容重新经过封闭形状／策略／频道分类校验，不能直接将原始行返回 UI。
查询要求当前有效会话及持久化 `RunDiagnostics`；Protected 另需 `ExportProtectedDiagnostics`。
会话租约只包围同步短段，不跨 await／IO；读取后二次核对会话及权限修订。
WPF 的 Maintenance 面板支持双频道、健康和有界查询；锁屏、登出、切换频道、离开页面或关闭会清除内容，
在途查询不能恢复旧数据。样例请求上限不超过已配置策略。

## 部署与未处理异常

显式策略须匹配当前已签名 Trace Storage Policy 快照哈希及规则版本，两个频道的可执行保留不得短于对应 Trace 最低保留，
且 Protected 短于 Safe。实际策略、目录和安装绑定参与生产 LoggingPolicy／DiagnosticPolicy 指纹。
缺少策略、安装未通过或缺少诊断报警映射时，不接受生产 Ready；异步激活完成前保持拒绝。
准入刷新仅比对不可变策略及已完成物理激活的内存状态，不同步重读诊断目录。
后续目录校验属于固定输出／查询所有者；失败或挂起进入健康与 Alarm Policy，不在生产轮询中等待。
不承诺闲置期间立即发现 ACL 修改，也不新增隐含的后台重验周期。
激活或输出发生物理故障后不自动重试，需要修复部署并受控重启。旧 SQLite profile 字节和 schema 39 保持兼容，
兼容读取不等于满足新增生产准入。

`IManagedFaultBoundary` 先启动现有 Fault Abort／关闭流程，再 best-effort 发射和有界 flush。
Runtime 的普通诊断关闭放在 `finally`，权威关停抛异常也不会跳过；原始关停失败和未确认结果保持原义。
`ManagedFaultShutdown` 接管 WPF Dispatcher 与 AppDomain 顶层故障，禁用操作输入并最终非零退出；
Dispatcher 的 handled 只用于受控关闭，不能继续运行。正常关闭的显示故障处理与致命边界分开。
致命路径在 Runtime 有界关闭尝试后用 Windows `TerminateProcess(GetCurrentProcess(), 1)` 自终止，
不启动普通 `Application.Shutdown`／CLR `ProcessExit`／DLL detach 回调；普通关闭不使用此路径。
Domain 回调不能因另一个线程已占用退出标记而返回，必须自己执行终止；Runtime 关闭仍只启动一次。
这会跳过剩余 finally／SDK 清理，未提交工作依赖既有崩溃恢复，不代表全部关闭操作成功。
自终止成功不返回是 Windows 平台前提；若 API 非预期返回，进程保持终端等待外部监督终止，
此未覆盖的平台故障不具有进程内终止期限保证。OS 待处理 IO 也可能推迟进程对象退出，不能声称硬实时。
相关平台语义见 [Windows 自进程终止契约](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-terminateprocess)。
没有自动进程 dump。临时 capture 提权及 SupportBundle 属于后续 T58，本票只冻结相关策略上限。
